# Prompts d'images manquantes — Marius Dumas Home

Deux catégories de visuels manquent sur le site. Génère-les avec ChatGPT (DALL·E) en collant les prompts ci-dessous tels quels, puis envoie-moi les images : je les intègre et je mets à jour le code/les fiches produit.

Style général à garder cohérent sur toutes les images : photographie d'intérieur réaliste, lumière naturelle douce, palette sauge/or/terracotta, esthétique éditoriale "magazine déco" (pas de rendu 3D, pas de style cartoon).
